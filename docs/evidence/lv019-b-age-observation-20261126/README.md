## Ejecución aislada del 26 de noviembre de 2026

Los primeros seis casos verifican la pieza candidata; los últimos cuatro caracterizan las guardas existentes y no constituyen aceptación de la política solicitada. La prueba de concurrencia sincroniza ambos barridos después del escaneo y antes de iniciar sus transacciones; no afirma lecturas transaccionales simultáneas. La reejecución del callback se provoca mediante un aborto inyectado. La respuesta descartada se simula después del commit y se concilia con una lectura antes de repetir. La colisión real en `create` rechaza el commit con las dos escrituras preparadas. La reapertura, borrado y recreación conservan las observaciones previas sin atribuirles titular.

El guard de Node emitió `VISTAVO_FINANCIAL_NETWORK_GUARD_ACTIVE SELF_CHECK=PASS`, preservado en `fixture.stderr.txt`; no sustituye un firewall del sistema para Java o código nativo. ## Preparación portable para una ejecución futura revisada

El lanzador requiere Windows y PowerShell 7, Node y JDK instalados, las dependencias del proyecto, el JAR del emulador con el hash fijado en el lanzador y los puertos dedicados libres. Desde la raíz de un checkout separado se puede preparar un manifiesto nuevo con `node docs/evidence/lv019-b-age-observation-20261126/manifest.mjs prepare <jdk> <jar>`. Tras revisar archivos, procesos, puertos y ese manifiesto, el lanzador acepta `./docs/evidence/lv019-b-age-observation-20261126/run-inspected.ps1 -Node <node.exe> -Jdk <jdk> -Jar <jar> -Manifest <manifiesto-nuevo>`. El manifiesto de esta ejecución contiene rutas absolutas y no debe reutilizarse en otra máquina. Git también puede transformar los finales de línea de código al hacer checkout, por lo que las huellas de los insumos requieren comprobación nueva. Si una ejecución futura resulta incierta, conservar y conciliar la evidencia antes de considerar un reintento.

Para el corte WIP se revisaron nombres y contenido completo de los archivos preparados con `scan-staged.cjs`; el escaneo local por patrones de credenciales no sustituye una auditoría exhaustiva.
