# LV-005 · Exploración del logo de Vistavo

Rob pide «Definamos el logo con t3». Alcance de esta fase: tres direcciones visuales originales, revisión independiente DeepSeek/Kimi mediante respaldo OpenRouter autorizado y lámina comparativa con variantes pequeñas/monocromáticas. Codex prepara SVG editables y documenta recomendación; Rob escoge la dirección. No cambiar ni volver a publicar la web todavía.

Base: Vistavo, una palabra, vistavo.app. Web actual blanca/verde, Inter, tono claro/profesional para trabajadores y pequeños negocios. Producto: video, transcripción, traducción, subtítulos revisables y voz AI en expansión. Logo sin texto incrustado en símbolo; nombre escrito Vistavo. Debe funcionar en favicon16/24/32px, cabecera, móvil, fondo claro/oscuro y una tinta. No depender de banderas ni de un idioma, no prometer que todos los servicios estén operativos. Evitar detalles diminutos y combinar indiscriminadamente play/globo/micrófono.

Direcciones iniciales para contraste: A monograma V con gesto de encuadre; B dos líneas de subtítulo dentro de una forma propia; C dos piezas que se encuentran para expresar cambio de idioma. Son hipótesis de diseño, no marca registrada ni opciones aceptadas. No se acredita exclusividad legal ni revisión de marcas con una consulta de modelos.

Cierre de esta fase: archivos reales, comparación visual de las tres opciones y tamaños, revisión independiente leída/contrastada, criterio de recomendación y elección del propietario pendiente. Ningún despliegue por elegir una propuesta creativa. Registrar modelos/uso/costo observables y conservar informes completos privados.
