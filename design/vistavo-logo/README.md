# Vistavo · Propuestas de logo

Tres direcciones para elegir con Rob. Estado: exploración; no existe logo definitivo aprobado ni se ha cambiado la web.

- A: V + dos escuadras de encuadre. Recomendación conceptual inicial de ambos revisores; puede recordar un visor/escáner.
- B: dos ranuras de subtítulos dentro de una silueta redondeada. Más literal; puede parecer una tarjeta de texto.
- C: dos piezas con canal abierto. Más abstracta y amplia; no comunica video directamente.

Color actual: #0F6B45. Tinta oscura: #111827. Blanco: #FFFFFF. Sin degradados, filtros o dependencia del color para separar las piezas.

Cada símbolo tiene SVG verde, negro y blanco, viewBox64x64. Las firmas SVG conservan Vistavo como texto editable en Inter600; instalar esa fuente para reproducir la tipografía. No son aún el paquete final con tipografía convertida a contornos. Licencia de fuente: Inter-OFL.txt, procedente del repositorio existente.

comparativa.svg es la lámina editable; su PNG y las exportaciones reales16/24/32/128px se guardan en outputs/vistavo-logo. Renderer privado @resvg/resvg-js2.6.2; no añade dependencias a la app. outputs/vistavo-logo/generate.mjs permite reconstruirla con las fuentes del repo. raster-check.json acredita tamaños, tinta y margen; no acredita reconocimiento humano ni aceptación multicultural.

Después de elegir dirección: afinar símbolo/espaciado, preparar firmas con contornos y favicon, fijar área de protección/tamaños y comprobar su aplicación. La elección de una dirección no autoriza por sí sola un despliegue. No se ha realizado búsqueda de similitud ni revisión legal de marca; una respuesta de modelo no acredita exclusividad.
